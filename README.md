# hisco-to-hisclass

This Python script facilitates the automatic mapping of HISCO codes to their corresponding HISCLASS categories. It leverages a CSV file containing predefined mappings and applies these to an existing dataset of occupational codes.

## 1. Prerequisites
- Python 3.6 or higher
- pandas library
- openpyxl library



## 2. Usage

- make sure the hisco codes in your excel database are in a column named 'hisco'
- download the jupyter notebook hisco-to-hisclass and the csv file with the hisco-hisclass-mappings
- change the filename in the notebook to the filename of the hisco-database you want to convert
- run the code!
